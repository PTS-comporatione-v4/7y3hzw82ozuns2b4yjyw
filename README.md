# CICADA 6845 // TEST 07

Fáza 2 pokračuje. Stroj ide naplno.

## Čo ťa čaká

Enigma I s plugboardom. Dva texty, len jeden je pravý.

**CESTA A** — prvý text:

`jfp xwowo ghadehaw 40, wunqm fu isyehz.`

**CESTA B** — druhý text:

`saztvd bo mzj dwrg, oafou fczo vgmxfdsm.`

Nastavenia (cryptii.com → Enigma machine, DECODE):
Model Enigma I, Reflector UKW A,
Rotor 1: II, Position 2 (B), Ring 1 (A),
Rotor 2: I, Position 17 (Q), Ring 2 (B),
Rotor 3: III, Position 10 (J), Ring 1 (A),
Plugboard: bq cr di ej kw mt os px uz gh, Foreign chars: Include.

Odpoveď je POSLEDNÉ slovo dekódovaného textu.

## Kódové súbory

V repe sú 4 kódové súbory (`pozicie.py`, `kruzky.js`, `plugboard.cpp`, `rotory.rs`).
Každý skrýva časť nastavenia stroja — bez nich Enigmu nenastavíš správne.
Kód je na čítanie, nie na spúšťanie.
